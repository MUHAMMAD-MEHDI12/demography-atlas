Why We Built HumanScape

Every day, millions of people search for population data. Students writing theses, researchers analyzing trends, journalists verifying facts, policymakers building strategies. Yet the data they need is scattered across dozens of websites, buried in Excel files, or locked behind technical interfaces. HumanScape changes that.

HumanScape is a free, open-source web application that brings together the world's most authoritative population datasets into a single, visually stunning interface. It shows how every country's age structure, deaths, and births change from 1950 to 2100 using data from the United Nations World Population Prospects 2024 -- the gold standard of global demographic data.

Built by GeoScape Analytics Lab, HumanScape is designed for anyone who works with population data: demographers, geographers, public health researchers, economists, urban planners, data scientists, and students at every level.

Technical Architecture

HumanScape is built with modern web technologies optimized for performance and accuracy:

  • Data Pipeline: A Python pipeline fetches UN WPP 2024 data, processes it into a compact binary format, and generates GeoJSON topology with country boundaries from Natural Earth
  • Frontend: TypeScript + Vite for blazing-fast builds; Canvas API for high-performance map rendering
  • Visualization: Custom SVG glyph system showing age pyramids, mortality curves, and fertility patterns -- all computed client-side from raw data
  • Pakistan Section: Dedicated census-level data for all 145+ districts, sourced from PBS Census 2023 and AJK Bureau of Statistics
  • GDP Data: World Bank API integration pulling 2025 GDP per capita for 178 countries
  • Country Areas: 100+ official area overrides from national statistics offices
  • Accessibility: Semantic HTML, ARIA labels, keyboard navigation, reduced-motion support, high-contrast dark mode

Data Verification

Every number on HumanScape can be traced back to its source. The build pipeline runs automated checks: population totals match UN published figures exactly (World: 8,091,735,000; India: 1,438,070,000; China: 1,422,585,000; Pakistan: 247,504,000). Deaths by age match official UN totals within a median of 0.2%.

Pakistan: A Deep Dive

The Pakistan section is one of HumanScape's most detailed components:

  • Complete Census 2023 data for all 145+ districts from the Pakistan Bureau of Statistics
  • AJ&K Census 2023 -- All 10 districts with population, sex, area, density, and growth rates
  • Gilgit-Baltistan data with population projections using growth rates from the 2017 census
  • District boundaries verified against OCHA administrative boundary files
  • Historical data from 1950 with projections through 2100
  • Pakistan's international borders -- India (3,323 km), Afghanistan (2,640 km), Iran (909 km), China (523 km)

For Researchers & Data Scientists

  • CSV Download: Export any country's data for analysis in R, Python, Excel, or any statistical software
  • Compare Mode: Overlay two countries on the same chart to see demographic differences side by side
  • 150-year timeline: Slide from 1950 to 2100 to watch demographic transitions unfold
  • Consistent methodology: The UN applies the same methods everywhere, making cross-country comparisons fair
  • Open source: All code is on GitHub -- fork it, modify it, build on it

The Vision

HumanScape started as a project to visualize Pakistan's census data. It has grown into something bigger: a complete, open, free portal to the world's population knowledge. Our vision is to make demographic data as accessible as a weather forecast -- something anyone can check, understand, and use to make better decisions.

We believe that when people can see how populations change -- the aging of Japan, the youth bulge of Sub-Saharan Africa, the urbanization of China -- they gain a deeper understanding of the forces shaping our world.
